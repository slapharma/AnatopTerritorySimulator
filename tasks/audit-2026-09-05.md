# Audit 2026-09-05 — four parallel agent reviews

Agents: (A) logic/flow audit, (B) security audit, (C) live GUI walkthrough as CCO, (D) static UX/content/spec review as CCO.
Verdict from all four: strong evidence discipline, but not trustworthy for a pharma decision-maker as-is.

## P0 — will break or mislead

1. **Parallel Round 1 races on `seq`** — `src/db.js:65-79` computes `MAX(seq)+1` outside the session lock; three concurrent opening turns collide. Insert failure happens after `flushHeaders` and outside the `try`, so the agent stays 409-locked for the process lifetime. Fix: wrap select+insert in `withSessionLock`; move `addMessage` (`src/app.js:296`) inside the `try`.
2. **VERIFIED tags are never checked against the tool trace** — `src/app.js:226-271` numbers any URL inside a tag as "cited". A fabricated URL gets a green badge, a citation and a Sources entry. Fix: cross-check against `open`/`search` trace entries; downgrade unmatched to ESTIMATE.
3. **Disagreement regex misses `⚠️` (U+FE0F) and stops at the first blank line** — `src/app.js:205,212` while `evidence-rules.md:22` demands blank lines. Real dissent silently dropped; export says "No disagreements were logged". Fix: `⚠\uFE0F?` and capture through the `Status:` line.
4. **Tool-round exhaustion stores pre-search chatter as the answer** — `src/agents.js:175-201`. Fix: final `streamOnce` with `tools: []`; only keep final-round text.
5. **Truncation (`finish === 'length'`) and Vercel timeouts leave clean-looking messages** — `src/agents.js:210`, `src/app.js:274-338`. Empty rows have no error, no Retry, and are skipped by later rounds. Fix: persist `stop_reason`, append visible truncation marker, treat old empty rows as failed, wall-clock budget in `runTurn`.
6. **Stored XSS via `mode`** — `src/app.js:279` unvalidated, rendered unescaped `public/app.js:361`. Any user can plant script that runs for the next admin (Basic Auth auto-attached). Fix: whitelist `mode`; `escapeHtml`.
7. **Stored XSS via markdown** — `public/app.js:63-74` `marked.parse` into `innerHTML`, no DOMPurify. Human moderator messages and LLM output are vectors. Fix: DOMPurify.
8. **Decision buried** — UI (`public/app.js:298-331`) and export (`src/export.js:96-122`) put GO/NO-GO after the full transcript. Fix: pinned Recommendation banner; export order Decision → Inputs → Disagreements → Verification → Transcript appendix.

## P1 — can break

9. Disagreements duplicate on restatement; RESOLVED never updates earlier UNRESOLVED (`src/app.js:207-218`). Dedup by normalised topic.
10. Moderator never sees the human's Resolved/Unresolved toggles or the disagreement log (`src/prompts.js:182-197`).
11. Mid-round failure not resumable; re-clicking round doubles agent messages (`public/app.js:646-676`).
12. Regenerate drops `instruction` for dive_deeper/custom (`public/app.js:416`).
13. No token budget; full transcript plus up to 10×8000-char pages per turn (`src/prompts.js:169-178`). Free-model context overflow is unrecoverable.
14. `running` guard is in-process; useless on Vercel (`src/app.js:203,285`). Move to DB.
15. Prompt-injection exfil via unrestricted `open_url` (`src/search.js:75`); inputs block sits in system prompt. Restrict to URLs from prior search results; wrap page text as untrusted; cap response size; block private IPs.
16. No cost/rate limit; `instruction` unbounded; any user can pick paid model. Cap length, per-user budget.
17. No session ownership: any user reads/exports/deletes every session (`src/app.js:117-164,341-360`).
18. `PATCH /api/defaults` not admin-gated (`src/app.js:107-114`) — global prompt poisoning.
19. Auth fails open on empty users table (`src/auth.js:58`); seed failure pins 401 for instance life (`src/auth.js:26-42`); scrypt per request, no brute-force limit.
20. Round order not enforced; Round 1 re-run sees transcript (`src/prompts.js:184-188`).
21. Empty form submits and burns three LLM turns with 12 INPUT MISSING. Make PRODUCT and COUNTRY required.
22. Reload mid-run shows "No messages yet"; in-progress rows invisible; second click gives 409 toast.

## P2 — UX and content (CCO lens)

23. Moderator prompt lacks exec summary, confidence level, explicit dissent section, SLA-function owners (`prompts/moderator.md:5-14`).
24. Jargon: "Section 0 of the spec", "ANTHROPIC_API_KEY", "Anthropic console" (`public/index.html:35,77`, `public/app.js:540,722,736`). Stale: backend is OpenRouter.
25. Naming inconsistent: session/turn/simulation/evaluation; Moderator (you)/You/Moderator (human); Decision Output vs Recommendation.
26. ALL-CAPS spec labels with no plain hints; budget options USD while evidence rules demand local + GBP (`src/prompts.js:40,71-89`).
27. Agent output structure unspecified; renderer relies on exact `**Next step:**` and `Position A/B` text. Mandate headings and word caps.
28. Sources tab and export list every searched URL, not only cited ones (`public/app.js:443`, `src/export.js:127-138`).
29. Rounds skip market access/pricing reconciliation, supply, IP, PV; Round 3 never converges on one base/upside/downside table (spec §3).
30. Export not board-ready: no TOC, no DOCX page numbers, ISO UTC timestamps, `dive_deeper` label missing (`src/export.js:25,74-83,102`), model per message not printed.
31. Header noise: model dropdown, stopwatch, "$0.000 · £0.000", footer model id. Hide for non-admins.
32. Landing auto-opens last session (someone else's transcript). Land on New session.
33. Mobile ≤900px unusable: sidebar hidden so no New session; topbar overflow 646px on 375px; right panel hidden so citation clicks go nowhere (`public/styles.css:265-272`).
34. `.filter-chips` padding `37px 20px 35px` wastes ~70px; 3px transcript overflow scrollbar (`public/styles.css:109`).
35. Exclusions checkbox grid misaligned (`.field label` rule leaks into `.check-item`).
36. Design-system violations: emoji glyphs despite MASTER.md "no emoji"; hit areas under 32px; muted `#64748B` at 11-12.5px.
37. Native `prompt()`/`confirm()` for rename, delete, reset password; Delete beside Export.
38. Guide explains buttons, not how to interpret GO WITH CONDITIONS, run time, cost, or trust levels.
39. No branded login page; Basic Auth browser dialog.
40. Schema not in repo; `prompts/{regulatory,clinical,commercial}.md` dead after DB-seeded agents (commit 3856114). Add `sql/schema.sql` and seed.
41. Tavily results carry no date; "within 3 years" rule unenforceable (`src/search.js:55-64`).
42. Postgres `rejectUnauthorized: false` (`src/db.js:6`); raw pg error messages returned to client (`src/app.js:362-365`).
