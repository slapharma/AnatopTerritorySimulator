Agent Profiles

Each agent's persona, background and standing questions live in prompts/agents/<key>/ — edit those files and commit to change who the agent is. Challenge level and tool abilities are per-deployment settings, editable here with no deploy needed, and the Knowledge box overrides the file for this deployment only.
