Anatop Territory Evaluation — User Guide

A working reference for colleagues new to the tool. It covers what the app does, how to run a session, and what everything on screen means.

What this is

A simulated cross-functional launch working group for evaluating whether — and how — to launch a pharmaceutical product in a specific country. Three AI agents (Regulatory, Clinical, Commercial) each play a specialist role, research the country live on the web, argue their case with evidence, and challenge each other's assumptions over several rounds. A fourth AI role (Moderator Assistant) synthesises the whole discussion into a structured decision document at the end.

It is not a source of truth on its own — it is a fast, structured first pass that surfaces what's known, what's estimated, what's genuinely unresolved, and where the agents disagree, each claim tagged and sourced so you can verify it yourself.

The dashboard

The dashboard is what you land on. It carries a summary of every evaluation run so far, the two things you are most likely to want to do next (start a new one, or pick up the most recent), and links to this guide, the agent profiles and — for admins — the admin page. The saved evaluations themselves live in All simulations in the sidebar, collapsed until you open it.

Above those sits a short How an evaluation runs panel explaining the four steps. Once you know them it is just taking up room, so it has an ✕ to dismiss it. That choice is remembered in this browser only — it does not follow you to another machine, and clearing site data brings it back.

Starting a session

  1. Click New evaluation in the sidebar.
  2. Fill in what you know. Every field is optional — anything left blank is passed to the agents as INPUT MISSING, and they are required to say what they assumed instead rather than silently guessing.
  3. Restore Default Values pre-fills the form with the saved default example (a real product, useful for a demo or a quick test). Any field you've saved as a default (see below) is included.
  4. Copy from last session pre-fills the form with whatever you entered last time.
  5. Click Start session and run Baselines. This runs all three agents in turn, each with live web search.

Note: Regulator and Reimbursement Bodies are not asked for — they follow from the Country you pick, and the agents identify them themselves as their first research step.

Saving your own defaults

Hover any field in the New Session form and a small Save as default button appears next to its label. Click it to make the field's current value the new default for everyone — the next person who clicks Restore Default Values gets it too. This is shared across the whole app, not just your browser.

The meetings

MeetingWhat happens
BaselinesEach agent answers its own questions independently, with no visibility of what the others will say.
ChallengeEach agent attacks at least two assumptions made by the others, backed by evidence — concede, rebut, or log a formal disagreement.
ConvergeAgents give base / upside / downside figures for timelines, cost, and revenue, working from the whole discussion so far.
Cross-talkOne free-form meeting: every agent reacts to the discussion so far, only where something genuinely changed their view.
Custom meeting…Write your own instruction and pick which agents respond to it.

You can also type directly into the message box at the bottom as the moderator — address it to one agent or all of them — and they'll reply.

After each of the four standard meetings finishes, the Moderator Assistant automatically writes up meeting minutes — a summary per agent plus collated action points — into the Intelligence panel's Minutes tab, and emails them to you with links to view the session, jump to that meeting's transcript, or approve moving to the next one.

Reading a response

Evidence badges

Every factual claim is tagged with exactly one of these:

VERIFIED checked against a real source, with a link
ESTIMATE a reasoned guess, with its basis stated
UNKNOWN needs a local in-market expert to settle

Numbered links like [1] next to a claim jump to that source in the Sources tab of the Intelligence panel (click Intelligence in the sidebar to open it), which lists every URL an agent searched or cited.

Closing labels

Every response ends with at least one of these, called out as a small coloured label — the single most important takeaway of that message, not a recap of the whole thing:

Next step Question Consideration Conclusion

Cross-references

In Challenge/Converge and cross-talk responses, a mention of another agent's name (e.g. "Clinical Agent") is a link — click it to jump straight to what that agent actually said.

Disagreements

When agents genuinely disagree, it's logged as a formal disagreement — shown in the Intelligence panel's Disagreements tab as each side's position, what evidence would settle it, and a status you can toggle between UNRESOLVED and RESOLVED. "↑ view in message" jumps back to where it was raised. Disagreements are never resolved by averaging two guesses — only by evidence or an explicit toggle from you.

Intelligence

Click Intelligence in the sidebar to pop out the right-hand panel: Sources, Disagreements, Decision (the recommendation, once one has been written), ★ Favourites, Reports, Minutes (auto-written meeting minutes), Agent notes (the transcript sliced by agent, by meeting, by disagreement, or by resolution status) and Inputs. Close it with the ✕ or Esc.

Favourites, Regenerate, Dive Deeper

  • ☆ Favourite — star any response to flag it. Starred responses are collected in the ★ Favourites tab of the Intelligence panel, where each one can be opened, jumped to in the transcript, or unstarred.
  • ↻ Regenerate — deletes a response and has the same agent answer again from scratch. Not offered on custom-round responses, since the original instruction isn't stored.
  • ⇊ Dive Deeper — responses are compact by default. This asks the same agent to expand one specific response in full depth, as a new follow-up message, without discarding the original.

Reading the transcript

Agent responses are laid out in three columns — Regulatory, Clinical, Commercial — always in that order, so a column position means the same agent everywhere on the page. An agent that did not speak in a round leaves its column empty rather than shifting the others along. By meeting and By time above the columns switch between grouping responses by round and running them as one continuous feed per agent.

The model selector

Each session can use a different underlying AI model — the dropdown in the top-right of a session picks it. Free models have no per-token cost but can be slower or rate-limited; paid models cost real money (broken down on the Admin page) but tend to be faster and more reliable for testing. A change applies to turns run from that point on, not retroactively.

Cost and timing

Each response shows how long it took to generate. The topbar's ⏱ clock is a running total of generation time for the current browser tab (it resets if you reload the page — it's a convenience stopwatch, not a stored record). The $ figure in the topbar is the API cost reported for the open session. The full breakdown — tokens, cache reads and writes, web searches, and a per-session table across every evaluation — is the Cost section of the Admin page. Cost is shown to admins only.

Writing the decision output

Once you've run at least one round, Reports → Final report in the sidebar triggers the Moderator Assistant to read the entire transcript and produce a fixed ten-section decision document — recommendation, regulatory pathway, clinical verdict, entry model, investment and breakeven, top risks, kill criteria, unresolved items, a verification appendix of every sourced claim, and next actions. It doesn't re-run the analysis or vote — it only synthesises what the three agents already established, keeping their tags and disagreements intact.

The result lands in three places: as a Moderator Assistant message in the transcript, in the Decision tab of the Intelligence panel, and in Reports, from where it can be exported or emailed. An Interim report works the same way at any earlier point, but does not write a decision.

Exporting

Export in the sidebar produces a Word (.docx) or PDF document of the full session — inputs, every message, sources, and the decision output if one has been written.
